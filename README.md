# Luxe Auto Detailing & Fleet CRM

A high-converting, luxury automotive detailing customer booking platform paired with a high-intent Meta Ads landing funnel and an operations Fleet CRM management system.

## Features

- **Luxury Hero & Meta Ads Landing Funnel (`/`)**: High-intent campaign tracker, dynamic 4-week capacity gauge, vehicle tier selector, and interactive before/after optical paint correction inspection slider.
- **Custom 4-Step Booking & Quote Calculator (`/book`)**: Real-time vehicle size multipliers, core package selection (5-Year Graphene Ceramic, Connoisseur Concierge Overhaul, etc.), bespoke add-on estimators, 4-week advance slot picker, and automated receipt generation.
- **Fleet CRM & Operations Management Portal (`/crm`)**:
  - Live revenue & bay capacity KPI dashboard.
  - Interactive pipeline table (Kanban/table status transitions).
  - Corporate fleet accounts manager with recurring monthly retainers and vehicle trackers.
  - Automated 3-stage quote follow-up sequences simulator (SMS & Email).

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **UI & Styling**: React 18, Tailwind CSS, Lucide React icons
- **Language**: TypeScript

## Getting Started

Install dependencies:
```bash
npm install
```

Run development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
